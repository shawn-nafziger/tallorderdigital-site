    What the tags mean

    LegitA season-long pattern, beyond the . The only tag in orange, because it's the only one that's signal.
    On purposeA choice, like shot mix, minutes or passing. Luck didn't do it, but it's still one night.
    FlukeMakes and misses, whistles or plus-minus on one night. Fun, and that's all.
    How it's picked

    Each morning a script checks every team, player and long shot from the night before for about 25 kinds of oddity.

    How rare is measured against history, only games before that night: team box scores since 2021-22, player box scores and shots since 2025-26.

    "About once a month" counts game nights: how many nights of history, divided by how many times it happened (plus one, so nothing is ever "infinitely" rare). Counting nights, not games, keeps player stats from winning just because there are more players than teams.

    The pick is the rarest, with a small bonus for kinds that are easy to picture. For variety, it's never the same kind of stat as either of the last two nights or the same team as the night before.

    Legit means a team's habit over the season is more than 2 standard errors from the league, the same bar the dashboards use for "beyond luck".

    Checked before it's posted: every number on the card is recomputed from the box scores by a separate script. Long shots only count in a quarter's last 5 seconds (an 83-foot "jump shot" on a game's first possession is a mislabeled shot), and shot-mix stats only count when the shot data has the whole box score.

    A night's pick never changes once it's posted, so each day's link always shows the same stat.
