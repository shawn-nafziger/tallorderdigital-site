Tall Order Digital - logo kit (working version, October 2026)

MARK (bars only)
  tod-mark.svg / .png ............ for light backgrounds
  tod-mark-on-dark.svg / .png .... for dark backgrounds (transparent)

APP ICON / SOCIAL AVATAR
  tod-app-icon.svg / .png ........ ink tile with the mark; use for profile pictures and app icons
  favicon.ico .................... website browser-tab icon (16/32/48 px)

FULL LOGO (mark + name)
  tod-logo-horizontal.svg ........ for light backgrounds
  tod-logo-horizontal-on-dark.svg  for dark backgrounds
  These keep the name as editable text in Barlow Semi Condensed (free from Google Fonts).
  They display correctly in web browsers; in design apps, install the font first.
  For a PNG of the full logo, export it from the design canvas in Claude.

Colors: orange #E8912D, slate #46536F, ink #1F2638, mist #F2F3F7
Final production files (text converted to outlines, spacing fine-tuned) should come from a designer.
